## 3. 사진

### 3-1. 무엇을 올리나

- **원본은 git에 올리지 않습니다.** 원본은 외장하드, 사진 클라우드처럼 git 밖에 따로 보관합니다. GitHub은 백업 서비스가 아닙니다.
- **웹용으로 변환한 사진만** `photos` 저장소에 올립니다.
  - 본 사진: 긴 변 2000px, WebP, 장당 약 300~500KB
  - 썸네일: 긴 변 400px, 장당 약 30~60KB
- 사진 안의 메타데이터(EXIF)는 **전부 지웁니다.** GPS 위치는 특히 반드시 지웁니다. 카메라, 렌즈, 필름, 노출 같은 촬영 정보는 보여주고 싶으면 `albums.js`에 글자로 따로 적습니다.

### 3-2. 용량 한도

| 한도 | 무엇을 세나 | 지운 사진도 포함? | 크기 |
|---|---|---|---|
| Pages 사이트 | 지금 공개된 파일 | 아니오. 지우면 바로 줄어듭니다 | 1GB (반드시 지켜야 함) |
| 저장소 | 과거 기록 전체 | 예. 계속 남습니다 | 1GB 권장, 5GB 강력 권장 |
| 파일 1개 | — | — | 50MB부터 경고, 100MB 넘으면 push 거부 |
| 트래픽 | — | — | 월 100GB 정도의 느슨한 제한 |

- 위 수치는 2026-11 기준으로 알고 있는 값입니다. 정확한 최신 값은 GitHub 공식 문서에서 확인합니다.
- git은 지운 파일도 기록에 남깁니다. 그래서 관리할 숫자는 **지금까지 올린 사진의 총합**입니다. 웹용으로 줄이면 1GB에 약 2,000장, 5GB에 약 10,000장이 들어갑니다.
- 이미 올린 사진을 다시 보정해서 올리지 않습니다. 같은 사진이 두 장 분량을 차지합니다.
- `photos` 저장소가 800MB를 넘으면 정리 방법을 정합니다.
  - 기록에서 사진을 완전히 지우려면 `git filter-repo`를 씁니다.
  - 또는 `photos` 저장소만 새로 만들어 기록을 처음부터 다시 시작합니다.
- Git LFS는 쓰지 않습니다. 브랜치 배포 방식에서는 Pages가 LFS 파일을 제대로 보여주지 않고, 사용량 한도도 따로 있습니다.

### 3-3. 내 컴퓨터에 사진을 두지 않으려면

- 사진을 지우고 커밋하면 최신 버전에서도 **삭제**되어 사이트에서 사라집니다.
- 대신 sparse-checkout으로 사진 폴더만 내 컴퓨터에서 뺍니다. 사진은 GitHub에 그대로 있고 내 디스크에만 없으며, 커밋해도 삭제로 잡히지 않습니다.

```bash
# photos 저장소에서. 사진은 img/ 아래에 둡니다 (예: img/2026/jeju/001.webp)
git sparse-checkout set --no-cone '/*' '!/img/'
```

- 처음 받을 때 `git clone --filter=blob:none`을 쓰면 사진 원본도 내려받지 않습니다.

### 3-4. 블로그에서 사진 부르기

- 사진 주소의 앞부분은 `data/site.js`의 `photoBase` 하나로 정합니다. 내 컴퓨터에서 미리 볼 때는 `/photos/`가 없기 때문입니다.
  - 배포된 사이트: `/photos/`
  - 내 컴퓨터(`localhost`): `https://cherryopener.github.io/photos/`
- 쓰지 않는 방법:
  - `raw.githubusercontent.com` 직접 링크: 이미지를 띄우는 용도가 아니라 느리고 요청 수 제한에 걸립니다.
  - git submodule: 사진이 블로그 사이트에 합쳐져서 블로그의 1GB 한도를 같이 씁니다.

## 7. 대학원 물리 책의 방향 (2026-11-18)

### 7-1. 목표와 독자

- 끝 목표는 **함수적 재규격화군(fRG, Wetterich 방정식)과 중력의 점근적 안전성**입니다. 그 위에서 가설을 세워 직접 계산하고, **석사 졸업 논문급 논문**(리뷰 논문급이어도 됨)을 한 편 쓰는 것까지 갑니다.
- 독자(사용자)는 석사 과정에서 양자장론을 배우고 곧바로 fRG 계산(매스매티카 패키지)에 투입되었습니다.
  - 통계역학·통계장론은 **전혀 모릅니다.**
  - 상대론, 블랙홀, 곡률 공간의 양자장론은 수강했지만 **많이 잊었습니다.** 다시 보면 이해되는 수준입니다.
- 그래서 **이 사이트의 앞선 책만 머릿속에 있다고 가정**합니다. 대학원 책은 사이트의 앞선 책 밖의 지식을 전제하지 않습니다.
  - 각 책 GUIDE.md에 "이 책이 전제하는 것: 사이트의 어느 책 몇 장" 표를 둡니다.
  - 그 밖에 필요한 것은 그 책 안에서 새로 세웁니다.
  - 처음 쓰는 개념마다 앞 책의 정의로 링크를 겁니다.

### 7-2. 책과 읽는 순서

| 순서 | 책 id | 핵심 |
|---|---|---|
| 1 | `math-phys-grad` | 군과 표현, 미분기하·올다발, 함수 해석, 점근 해석, **범함수 방법(범함수 미분, Tr log, 그라스만 적분·초대각합, 열핵)** |
| 2 | `qm-grad`, `em-grad` (병렬) | 양자역학은 마지막 부에서 유클리드 경로적분 → 유효 작용 → 0+1차원 fRG 맛보기. 전자기학은 공변 형식과 자연 단위로 끝냄 |
| 3 | `relativity` | 아인슈타인-힐베르트 작용, 사다리꼴 형식, 배경 위 섭동과 York 분해, ADM |
| 4 | `qft` | 1PI 유효 작용, RG와 유효 장론, 비가환 게이지·BRST·ST 항등식, 배경장 방법, 유클리드 장론, 후지카와 방법 |
| 5 | `frg` | 1부 **통계장론 처음부터**(통계역학, 이징·O(N), 평균장, 임계 현상, 윌슨 RG, ε 전개). 양자 중력에 덜 쓰이는 것은 1부 마지막 장에 요약. 이어서 Wetterich 방정식, 계산의 원리, 근사, 페르미온·게이지 |
| 6 | `asymptotic-safety` | 1부 곡률 공간의 양자장론 → 와인버그·Reuter → EH·f(R) 근사 → 중력-물질 → 열린 문제 → **연구로**(재현 패키지, 논문 쓰기) |
| 선택 | `cm-grad`, `black-holes` | 필수 경로 밖. 고전장론과 뇌터 정리는 `qft` 1장이 직접 세움 |

- 각 책의 참고서와 전제 장은 `data/books.js`의 `plan` 필드에 적었습니다.
- 가목차는 `chapters`(장 status `"slot"`)에 넣고, 책 status를 **`"outline"`(목차 공개)**으로 두었습니다(2026-11-18).
  - 책 홈(`books/<id>/index.html`)에는 서재 경로 그림, 이 책의 지도, 전체 목차만 있습니다. 장 파일은 없습니다.
  - 그래서 엔진은 outline 책의 장 링크를 책 홈의 그 장 카드(`index.html#ch01`)로 보냅니다. 홈의 "챕터 수"는 빈 슬롯을 세지 않습니다.
  - 정식 기획(GUIDE.md) 때 CLAUDE.md 4절의 기획 모델(L4: fable/high, L5: fable/xhigh)이 가목차를 다듬고, 장 파일을 만든 뒤 책 status를 `"writing"`으로 바꿉니다. 책 홈도 그때 다시 씁니다.

### 7-3. 참고서 고르는 기준

- 모든 책이 fRG와 점근적 안전성으로 모이도록 거꾸로 고릅니다.
- 책마다 **뼈대 한 권**(장 순서와 범위), **보조**(깊이와 관례 확인), **검산**(계산 결과 대조)을 둡니다.
- CLAUDE.md 1절대로 순서와 주제만 참고하고, 문장·예제·문제는 새로 씁니다.
- 서브에이전트는 유료 교재를 직접 펼쳐 볼 수 없습니다. 최근 연구를 다루는 장(fRG·점근적 안전성의 후반부, 블랙홀 정보 역설)은 **arXiv 원문**을 주 출처로 읽습니다(CLAUDE.md 4-4절 보정).
- 뼈대: 수리물리(대학원) Stone–Goldbart, 양자역학 Sakurai–Napolitano 3판, 전자기학 Jackson 3판(범위)·Zangwill(설명), 상대성이론 Carroll, 양자장론 Srednicki, fRG Kopietz–Bartosch–Schütz, 점근적 안전성 Reuter–Saueressig. 나머지는 `books.js`의 `plan.refs`.
- 판과 연도는 기억에 기대어 적은 것이라, 정식 기획 전에 한 번 더 확인합니다.

### 7-4. 공통 관례

| 항목 | 관례 | 이유 |
|---|---|---|
| 계량 | 모든 대학원 책에서 \((-,+,+,+)\) | 학부 `math-phys` 22장, Carroll, Srednicki, 점근적 안전성 문헌과 같음. \(t \to -i\tau\)로 유클리드 \((+,+,+,+)\)가 바로 나옴. Peskin 식은 부호를 바꾸고 바꿨다고 적음 |
| 단위 | `em-grad`는 처음부터 끝까지 SI. 마지막 장에서 헤비사이드-로런츠 자연 단위로 다시 씀. `qft`, `relativity`, `frg`, `asymptotic-safety`는 \(\hbar = c = 1\) | 학부 책과 이어지고, 양자장론 표기로 자연스럽게 넘어감 |
| 푸리에 변환 | 학부 `math-phys` 15장과 같이 \(2\pi\)를 역변환 쪽 측도에 둠: \(\int d^4k/(2\pi)^4\) | 양자장론 관례와 같음 |
| fRG 표기 | 조절 함수 \(R_k\), 흐름 시간 \(t = \ln(k/\Lambda)\), \(\partial_t \Gamma_k = \tfrac12 \mathrm{STr}[(\Gamma_k^{(2)} + R_k)^{-1}\partial_t R_k]\) | `math-phys-grad` 5부에서 먼저 확정하고 뒤 책은 링크로 씀 |

### 7-5. 계산 트랙 (손 계산 + 코드)

- 사용자는 석사 때 남이 만든 매스매티카 패키지로 계산했는데, 원리가 공개되지 않아(대외비) 고생했습니다. 그래서 **블랙박스 없이 원리부터** 보여 줍니다.
- 계산이 나오는 장은 같은 계산을 세 번 보여 줍니다.
  1. **이론**: 유도와 근거
  2. **손 계산 상자**: 가장 작은 경우를 행렬 계산으로 끝까지 풂
  3. **코드 상자**: 같은 결과를 Python으로 처음부터 짜고, 손 계산 값과 맞는지 확인한 뒤에 넓힘
- fRG 계산의 일곱 단계와 무료 도구:

| 단계 | 하는 일 | 도구 |
|---|---|---|
| ① 전개 | 작용을 배경장 주위로 2차까지 전개해 헤세 \(\Gamma^{(2)}\) | 스칼라: SymPy. 중력 텐서: Cadabra2 |
| ② 분해 | 요동장 분해(York), 게이지 고정, 유령 → 블록 행렬 | SymPy |
| ③ 대각합 | 조절 함수 \(R_k(\Delta)\), 열핵 전개, Q-범함수 | SymPy, mpmath |
| ④ 투영 | 연산자 기저에 투영해 β 함수 | SymPy |
| ⑤ 고정점 | 근 찾기, 안정성 행렬 고윳값 → 임계 지수 | NumPy, SciPy |
| ⑥ 흐름 | 결합 상수 ODE, 퍼텐셜·f(R)의 PDE(격자, 체비쇼프) | SciPy (빠른 계산이 필요하면 Julia) |
| ⑦ 검증 | 1루프 극한, 가우스 고정점, 조절 함수·게이지 의존성, 문헌 수치 | 직접 작성 |

- 작은 예제는 **Pyodide**(브라우저용 Python, NumPy·SciPy·SymPy 포함)를 CDN에서 버전을 고정해 불러와 페이지에서 바로 실행합니다. 빌드 단계는 만들지 않습니다. 중력 텐서처럼 무거운 계산은 내려받는 `.py` 파일로 둡니다.
- `frg` 책에 "Claude와 함께 계산하기" 장을 둡니다. 유도 → 단계별 작은 함수로 구현을 맡김 → 손 계산 값으로 시험 → 두 방법 교차 확인 → 확장. AI가 짠 코드도 검증 없이는 블랙박스라는 점을 가르칩니다.
- Wolfram Engine의 무료 개발자 판은 사용 조건이 까다로워서 기본 경로로 삼지 않습니다.

### 7-6. 논문까지

- `asymptotic-safety` 책의 마지막 부 「연구로」가 맡습니다.
  1. 재현: Reuter 고정점, f(R) 다항식, 중력-물질 결과를 이 책의 코드로 다시 계산
  2. 주제: 책을 끝낼 즈음 최근 arXiv를 읽고 함께 고름. 후보는 조절 함수·게이지 의존성의 체계적 비교, 덜 다뤄진 물질 계, 오픈 소스 Python 재현 코드와 교육용 리뷰
  3. 실무: LaTeX 원고, arXiv 첫 제출의 추천(endorsement), 학술지의 AI 사용 공개 규정, 가능하면 원고를 봐 줄 공동 연구자
