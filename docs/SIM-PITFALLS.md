# 실험 코드에서 자주 하는 실수

`assets/sims/`의 인터랙티브 실험을 쓰거나 고칠 때 먼저 읽습니다. 실제로 저지른 실수를 하나씩 모읍니다. 새 실수를 찾으면 같은 형식으로 덧붙입니다.

---

## 1. 전기력선을 양전하에서만 출발시킨다

**발견**: 2026-11-17, 수리물리학 4장의 `efield` 실험 (`assets/sims/phys.js`)

### 증상

- 쌍극자인데 그림이 좌우 대칭이 아닙니다.
  - 양전하 주변에는 사방으로 뻗는 선이 있습니다.
  - 음전하 주변에는 양전하 쪽에서 오는 몇 가닥만 들어오고, 바깥쪽은 비어 있습니다.
- 알짜 전하가 음수인 배치(예: 음전하만 여럿)에서는 선이 아예 없거나 엉뚱하게 그려집니다.

### 원인

양전하에서만 선을 출발시키고, 선이 화면 밖으로 나가면 추적을 멈췄습니다.

- 실제 쌍극자에서는 양전하에서 바깥으로 나간 선도 크게 돌아서 결국 음전하로 들어옵니다.
- 하지만 화면 밖에서 멈추면 그 "돌아 들어오는 반쪽"이 그려지지 않습니다.
- 그래서 음전하 쪽의 선이 늘 모자랍니다.

### 고치는 법

1. **모든 전하에서 출발합니다.** 개수는 |q|에 비례하게 잡습니다. 가우스 법칙에 따라 전하에 드나드는 선의 수는 |q|에 비례해야 합니다.
2. **방향**
   - 양전하: **E** 방향으로 추적합니다.
   - 음전하: **−E** 방향으로 거꾸로 추적합니다.
3. **중복 제거**: 음전하에서 거꾸로 추적한 선이 양전하에 닿으면, 그 선은 양전하가 이미 그렸으므로 버립니다. 화면 밖으로 나가는 선만 남깁니다.
   - 반대로 해도 됩니다. 한쪽 부호만 "전하–전하 선"을 맡으면 됩니다.
4. **출발 각도**: 음전하의 출발 각도를 양전하의 거울상으로 잡습니다. 예를 들어 양전하가 `+0.1`이면 음전하는 `−0.1`입니다. 그래야 쌍극자 그림이 정확히 대칭이 됩니다.
5. **화살표는 언제나 E 방향**으로 그립니다. 거꾸로 추적한 선이라도 화살표까지 뒤집지 않습니다.

```js
Q.forEach((c) => {
  const sign = c.q > 0 ? 1 : -1, n = 10 * Math.abs(c.q);
  for (let k = 0; k < n; k++) {
    const a = (k / n) * TAU + sign * 0.1;          // 음전하는 거울상 각도
    // ... sign * E 방향으로 추적하며 점을 모은다. 화면 밖이거나 다른 전하에 닿으면(hit) 멈춘다
    if (sign < 0 && hit && hit.q > 0) continue;   // 양전하가 이미 그린 선
    // 선을 그리고, 화살표는 +E 방향
  }
});
```

### 점검

- [ ] 쌍극자 그림이 가운데 수직선을 기준으로 좌우 대칭입니다.
- [ ] 음전하 주변에도 사방에서 들어오는 선이 있습니다.
- [ ] `+2와 −1` 배치에서 +2 쪽 선이 대략 두 배입니다.
- [ ] 음전하만 놓았을 때 바깥에서 들어오는 선이 그려지고, 화살표가 음전하를 향합니다.

### 같은 함정이 있는 곳

선을 "원천에서만" 출발시키는 모든 그림에서 같은 문제가 생깁니다.

- 자기력선: 막대자석의 N극과 S극, 전류 고리
- 유체의 원천(source)과 흡입(sink)
- 열의 흐름선

이런 그림은 **흡입 쪽에서도 거꾸로 추적하고, 중복만 지우는** 같은 방법으로 그립니다.
