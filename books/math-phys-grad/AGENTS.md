## A. 집필 에이전트

너는 『수리물리학 (대학원)』(책 id `math-phys-grad`, L4 고급. 21장만 L5)의 **NN장**을 쓰는 집필 에이전트다. 기준 장인 1장은 사용자가 확인했다. 1장의 모양을 따른다.

### 읽을 것
1. `CLAUDE.md` 1절
2. `books/math-phys-grad/GUIDE.md`의 다음 부분. 전부 읽지 않아도 된다.
   - 0~7절, 9절
   - 8절에서 **자기 장의 항목과 선수 장의 항목**
   - **11절 전체**. 11-0은 기준 장에서 정한 모양이고 반드시 따른다. 11-4는 이미 쓴 장의 `id`와 렌더링된 번호다.
3. 맡은 파일 `books/math-phys-grad/chapters/chNN.html`. 템플릿을 복사해 둔 빈 장이고, `<body>` 속성과 `<title>`이 채워져 있다. `<meta name="description">`은 지금 절 목록이니 장 요약 한 문장으로 바꾼다.
4. 형식의 본보기는 `books/math-phys-grad/chapters/ch01.html`이다. **필요한 부분만 찾아 읽는다.** 손 계산 상자 하나, 코드 상자 하나, 예제 하나, 연습문제 하나, 퀴즈, 핵심 정리 정도면 된다.
5. 선수 장이 이미 쓰였으면 그 장의 파일에서 링크할 `id`를 `grep -o 'id="[a-z]*-[^"]*"'`로 확인한다. 아직 쓰이지 않은 장은 GUIDE 8절의 계획 `id`로 **번호 없이** 링크한다.
6. 학부 책 `books/math-phys/chapters/`는 GUIDE 0절 표의 `id`로 이름만 써서 링크한다. 예: "학부 7장의 생성자".

### 쓰는 법 (요점)
- 절 제목과 순서는 GUIDE 8절의 "절" 목록을 그대로 따른다. 미리 정한 `id`는 이름을 바꾸지 않는다.

- 계산 트랙: 이론 → 손 계산 상자 → 코드 상자(GUIDE 1-2, 4-2, 11-0).
  - 코드는 상자에 넣는 그대로 파일로 저장해 `python3`로 실제로 돌린다.
  - 기대 출력은 실행 결과를 그대로 붙인다.
- 분량은 130~150KB다. 절 하나가 25KB를 넘으면 나누자고 보고서에 제안한다.
- 교재의 문장, 예제, 문제를 옮기지 않는다. 순서와 주제만 참고한다.
- 본문은 한다체다.

### 검산 (GUIDE 9절)
- 모든 식, 숫자, 표, 연습문제 풀이를 코드나 손으로 다시 확인한다.
- 스크립트는 메인 세션이 준 scratchpad의 `chNN/` 아래에 둔다. 저장소에는 넣지 않는다.
- 끝나면 HTML을 스크립트로 점검한다.
  - 태그 짝, `id` 중복
  - `a.ref` 대상
  - `\( \)`, `\[ \]`의 짝
  - 참조 뒤 조사(을/를, 와/과)
  - 미리 정한 `id`가 모두 있는지
  - **종류 이름 중복 0건**: 정규식 `(정리|예제|정의|손 계산|코드|문제|수학 상자) <a class="ref" href="#(thm|ex|def|calc|code|prob|math)-`. 렌더링하면 "정리 정리 2.1"이 된다(2장 검토에서 32곳).
  - **`eq-` 참조 바로 앞이 "식"**인지. "정의 (2.30)", "사영 연산자 (2.30)"처럼 쓰면 번호가 정의나 정리 번호로 읽힌다.
  - `\qquad`, `\quad`로 식 둘을 한 줄에 잇지 않았는지
  - `class=\"` 꼴(이스케이프된 따옴표)이 0건인지(14장 검토)
  - 점근 뜻의 \(\sim\)에 방향(\(x \to 0^+\) 등)이 있는지(핵심 정리, 문제, 풀이까지). 인라인 분수 `1/\sqrt2\pi`는 `1/(\sqrt2\,\pi)`로 묶는다
- 휴대폰 폭(375px)을 미리 생각하고 쓴다. 상자 안 디스플레이 식은 한 줄 약 256px, 접은 증명·풀이 안은 약 225px다. 넘을 것 같으면 `aligned`로 나눈다. 인라인 수식 안에 긴 숫자 목록을 넣지 않는다. 인라인 수식은 줄바꿈되지 않는다. SVG 안의 선과 글자는 viewBox 밖으로 나가지 않게 한다. 나가면 375px에서 페이지 전체가 가로로 넘친다.
- 브라우저 렌더링 점검은 메인 세션이 한다.

   - GUIDE 11-0의 규칙: 정리 이름 뒤에 식 번호를 바로 붙이지 않음, "(n.k절)" 꼬리표, `\qquad` 금지, 인라인 `<style>` 금지

   - 학습 목표마다 퀴즈나 문제가 있는지
   - "어디에 쓰이나" 문장이 정확한지. 뒤 책의 장 번호는 `data/books.js`의 그 책 가목차로 확인한다.
   - 앞뒤 장의 몫을 침범하는지
7. **분량**(130~150KB, 절당 25KB 이하), 한국어 문장과 용어(GUIDE 5-9, 11-3), 교재 문장을 옮긴 흔적
